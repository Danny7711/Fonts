Использование нескольких шрифтов

Задание 1 — Google Fonts

Для заголовков данной страницы используется шрифт Roboto, который подключён с помощью Google Fonts.

Для основного текста используется шрифт Open Sans, также загруженный с Google Fonts.

Благодаря подключению нескольких шрифтов можно использовать разные стили для заголовков и основного текста.

Задание 2 — Альтернативные шрифты

В CSS можно указать несколько шрифтов через запятую. Если первый шрифт недоступен, браузер автоматически попробует следующий.

Например: Roboto, Arial, Helvetica, sans-serif. В первую очередь будет использоваться Roboto. Если он недоступен, будет выбран Arial.

Montserrat — дополнительный шрифт

Этот заголовок использует Montserrat, а текст написан с использованием Open Sans. Оба шрифта подключены с помощью Google Fonts.

Итог

В данной работе были использованы три шрифта Google Fonts: Roboto, Open Sans и Montserrat.

Также были указаны альтернативные шрифты через запятую. Это позволяет странице корректно отображать текст даже в случае, если основной шрифт недоступен.
